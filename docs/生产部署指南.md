# 生产部署指南（售后管理平台）

> 适用：把开发环境（frappe_docker + aftersales 应用）搬到正式服务器对外使用。
> 原则：与开发环境同构（Frappe 16 + ERPNext + aftersales），数据从零开始（历史数据不迁移是既定决策）。

## 一、准备

1. 一台 Linux 服务器（2C4G 起），安装 Docker + Docker Compose 插件
2. 域名解析到服务器（如 `aftershall.yourdomain.com`），HTTPS 证书（推荐用宿主机 Caddy/Nginx 反代或 certbot）
3. 代码仓库可访问（Dockerfile 会 `bench get-app` 拉取）

## 二、构建镜像

```bash
cd deploy/
docker build -t aftersales-prod:latest \
  --build-arg BASE_IMAGE=frappe/erpnext:v16.x.x \        # 与开发环境大版本一致
  --build-arg APP_REPO=https://github.com/<组织>/aftersales.git \
  --build-arg APP_BRANCH=master .
```

## 三、启动

```bash
cp .env.example .env    # 修改 DB_ROOT_PASSWORD
docker compose --project-name aftersales up -d

# 首次建站（一次性）
docker compose --project-name aftersales exec backend \
  bench new-site aftershall.yourdomain.com \
  --db-root-password=<.env里的密码> --admin-password=<管理员密码> \
  --install-app erpnext --install-app aftersales

# 把站点写入 frontend 识别（或配置 hosts）
docker compose --project-name aftersales restart frontend
```

启动后 after_install 自动创建全部 DocType/角色/审批流/打印模板（无需手工 migrate 脚本）。

## 四、HTTPS

最简方案（推荐）：宿主机装 Caddy：

```
aftershall.yourdomain.com {
    reverse_proxy 127.0.0.1:80
}
```

Caddy 自动申请续期证书；此时 compose 里可只留 80 端口。

## 五、每日自动备份

```bash
# 编辑 deploy/.env：SITE=aftershall.yourdomain.com，BACKUP_RETENTION_DAYS=14
chmod +x backup.sh
crontab -e   # 加入：
30 1 * * * /opt/aftersales/deploy/backup.sh >> /var/log/aftersales-backup.log 2>&1
```

备份内容：数据库 gzip + 附件 tar（含私有文件），落到宿主机 `/opt/aftersales/backups`，自动清理超期文件。

恢复（演练过才算有备份）：

```bash
docker compose --project-name aftersales exec backend \
  bench --site aftershall.yourdomain.com restore <备份文件.sql.gz> --with-files <附件tar>
```
