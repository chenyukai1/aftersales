## 3. 一条完整业务故事（约 8 分钟）

**故事背景（可讲给观众）**：上海沪联的电动叉车（CPD20）货叉出现锈蚀穿孔，司机报修到销售，售后需要：登记→领导批→库房发新件→坏件寄回→月结索赔→质量问题是否要追根因。

### Step 1｜登记（售后 shouhou）约 2 分钟
1. 桌面点 **售后登记 → 新建**
2. 在「车架号/铭牌」输入 `HC-2026-0901-011`（回车/失焦）
   - **预期**：车型 CPD20、出厂日期、售后波段、**客户「上海沪联仓储设备有限公司」、对接人「陈国栋」** 自动带出
3. 三级故障定位：先选大类「车身与属具」→ 部件「货叉」→ 现象「锈蚀穿孔」
   - **预期**：现象选中后，**部件/大类自动回填**；现象文本自动拼入故障描述首行
   - **话术**："原来登记要手打故障部件，现在点三个下拉，而且字典后台能维护，数据是标准的"
4. 故障描述补一句：`货叉表面锈蚀穿孔，影响托货安全，客户要求更换。`
5. 「配件明细」点 **添加行**，老配件编码输入 `31101130`
   - **预期**：配件名称、供应商「江苏威博」、索赔需求自动带出；坏件寄回自动为「是」；数量默认 1
   - 顺手拍一张现场照片传附件 → **预期**：文件自动归档到 `售后资料/上海沪联仓储设备有限公司/2026-09/货叉/`
6. 点 **保存 → 提交审批**（服务单号自动生成 `service-2026-xxxx`）
   - **话术**："从录单到提交，人工输入只有铭牌、故障描述、配件编码三样，其它全是系统带出"

### Step 2｜审批（主管 zhuguan）约 1 分钟
1. 右上角切换登录 `zhuguan@demo.local`
2. 打开该服务单 → 状态「待审批」→ 点 **审批通过**
   - **预期**：状态变「已通过」；OA 栏状态自动回写 N（特殊申请回写 Y，预留了外发 webhook 通道）

### Step 3｜自动出库（可切回 shouhou）约 2 分钟
1. 打开该服务单 → 底部/关联可见 **索赔单已自动生成（草稿）**
2. 进入索赔单 → **生成出库单**
   - **预期**：自动创建 ERP 出库单（Delivery Note），**服务单号已写入出库单备注**；提交出库单后索赔单状态「已出库」、登记 ERP 录入自动变 OK
   - **话术**："以前要手工去 ERP 做出库、还要记服务单号，现在一键联动，单号也不会串"

### Step 4｜坏件追回（机制演示）约 1 分钟
1. 打开登记单 → 配件行「坏件寄回=是」已生成**旧件追回单**
2. 打开追回单：展示提醒子表；**话术说明**："系统每日自动扫描，发货满 7 天进入提醒、此后每周提醒一次（推待办/企微），超 60 天未寄回自动标记超时终止——坏件不会烂在客户那儿"

### Step 5｜索赔清单（机制演示）约 1 分钟
1. 打开 **供应商索赔清单** 列表（按供应商维度）
2. 演示已自动生成的月度清单：点开 → **打印「供应商索赔清单」**
   - **话术**："每月 1 号系统自动汇总上月各供应商索赔，直接打出来给供应商对账，不用财务月底熬夜拉数"

### Step 6｜质量闭环（质量 zhiliang）约 1.5 分钟
1. 切换登录 `zhiliang@demo.local`
2. 打开 **质量闭环** → 新建，关联本登记（或从批量隐患入口：近 7 天同部件 ≥3 起系统已自动预警）
3. 走一遍五阶段面板：定性（如：功能失效-产品设计）→ 吹哨分级（黄）→ 批量排查 → 原因评审（填评审日期）→ 8 步落地动作
   - **预期**：完成后闭环状态「完整闭环」，登记单自动回写"已闭环"
   - **话术**："这单虽然是个案，但如果三天里同部件坏三台，系统会提前预警——把'救火'变成'治根'"

### Step 7｜收尾（可选，30 秒）
- 打印 **售后登记表**：演示表单打印模板排版（A4 正式样式）
- 打开 **售后设置**：给观众看一眼"通知渠道/外部系统接口"预留位（企微 webhook 填了即推群）

## 5. 演示翻车预案

| 现象 | 处理 |
|------|------|
| 输铭牌没带出客户 | 该车未维护"购车客户"列 → 用已知演示铭牌 `HC-2026-0901-011` |
| 生成出库单报"缺 ERP 物料" | 该配件未绑定 ERP 物料 → 换用 `31101130`，或先在配件主档补 erp_item |
| 登记提交报权限 | 确认当前是 shouhou@demo.local 且处于草稿→提交审批 |
| 清单列表为空 | 索赔清单 cron 每月 1 日跑 → 手动执行 `bench --site dev.localhost execute frappe.get_attr('aftersales.after_sales.doctype.claim_list.claim_list.generate_monthly_claim_list')()` 演示 |
| 想现场造批量隐患 | 用 shouhou 对同一配件 `31101130` 快速录 3 张登记并提交 → 稍后质量端出现预警 ToDo |
