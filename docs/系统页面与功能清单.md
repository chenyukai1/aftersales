## 一、页面入口总览

系统所有售后页面都挂在 **「售后管理」工作台**（登录后桌面首页），共 14 个快捷入口：

| # | 入口 | 类型 | 页面定位 |
|---|------|------|---------|
| 1 | 质量分析看板 | 分析页面 | **M5 分析端**：索赔率 / 故障TOP / 供应商对比 / 月度趋势 |
| 2 | 售后登记 | 业务单据 | **全系统主入口**（录单起点） |
| 3 | 质量闭环 | 业务单据 | 批量隐患 → 根因 → 改善落地 |
| 4 | 索赔单 | 业务单据 | M1 自动出库中间单 |
| 5 | 旧件追回 | 业务单据 | M2 坏件寄回跟踪 |
| 6 | 改进记录 | 业务单据 | 改进-再发比对数据 |
| 7 | 索赔清单 | 业务单据 | M3 月度供应商对账清单 |
| 8 | 配件主档 | 主数据 | 配件字典（登记/出库/索赔底座） |
| 9 | 整车发货 | 主数据 | 车辆档案（铭牌带出源） |
| 10 | 配件登记 | 主数据 | 特殊配件跟踪 |
| 11 | 售后选项 | 字典维护 | **所有下拉选项的可视化维护** |
| 12 | 故障字典 | 字典维护 | 故障大类/部件/现象三级 |
| 13 | 售后资料库 | 附件 | 归档的故障照片/文件 |
| 14 | 售后设置 | 单例配置 | 仓库/通知/外部接口 |

> 每个入口都含两个标准页面：**列表页**（查/筛/批量）+ **表单页**（编辑/操作/打印）。
> 除工作台外，也可用顶部搜索框直接输入名称（如"售后登记"）跳转。

## 二、业务单据页（核心操作）

### 1. 售后登记 Service Request ⭐ 全系统起点

| 面 | 说明 |
|----|------|
| 定位 | 客户故障报修录入；提交后系统自动触发后续全部单据 |
| 新建 | 左侧选单 → 新建；**默认已带**：反馈日期=今天、服务类型=普通索赔、处理措施=索赔配件、ERP录入=OK、OA=N |

**表单内自动行为（人工只填 铭牌/故障描述/配件编码）**

| 操作 | 自动带出 |
|------|---------|
| 输铭牌(车架号) | 车型/出厂日期/售后波段/出厂月份 + **购车客户/对接人** + 特殊配件跟踪(订单号｜状态) |
| 选客户 | 收件人/电话/收货地址/发货区域 预填配件行 |
| 三级故障点选 | 选"现象"→ 部件/大类自动回填 + 现象文本自动拼入故障描述 |
| 配件行输老配件编码 | 名称/供应商/索赔需求 带出；坏件寄回=是；数量默认 1；新件编码自动复制 |
| 上传照片 | 自动归档到 `售后资料/客户/年月/部件/` |

**操作按钮**（按状态显示）
- 保存 → **提交审批**（Workflow：草稿→待审批）
- 待审批：由 After Sales Manager 角色打开 → **审批通过 / 驳回**
- 已提交(已通过)且未建闭环：**「发起质量闭环」**（弹窗选定性 → 自动建闭环单）
- 打印：**售后登记表**（A4 正式版式）

**提交后系统自动做**（无需人点）：建索赔单(草稿) → 需寄回的建旧件追回 → 批量隐患自动建闭环 → 改进记录命中自动评论提醒 → OA 状态回写 + 外发事件。

---

### 2. 质量闭环 Quality Issue Closure

| 项 | 说明 |
|----|------|
| 定位 | M5：把个案/批量问题从"发件了事"推进到"根因+改善" |
| 创建 | 自动（批量隐患预警 或 登记单"发起质量闭环"）；质量端也可手动新建 |
| 表单 | 五阶段面板：定性 → 吹哨分级(红橙黄绿) → 批量处理(b/c类) → 原因评审 → 方案落地 |

**操作按钮**
- 评审通过且未闭环：**「标记完整闭环」** → 状态"完整闭环"，登记单回写已闭环
- 行动项子表：记录 8 步落地动作，与改进记录衔接

---

### 3. 索赔单 Claim Order

| 项 | 说明 |
|----|------|
| 定位 | 审批通过后系统**自动创建**（草稿）；每张登记 → 一张索赔单（挂配件行） |
| 操作按钮 | 状态=草稿 且有明细：**「生成出库单」** → 创建 ERP 出库单(Delivery Note)，**服务单号自动写入出库单备注** |

**状态流**：草稿 → (生成+提交出库单) → 已出库 → 完成；提交出库单后回写登记 ERP录入=OK。
> erp_recorded=——（无需录 ERP）的登记不生成索赔单。

---

### 4. 旧件追回 Old Part Recall

| 项 | 说明 |
|----|------|
| 定位 | 登记配件"坏件寄回=是"时自动建；跟踪坏件寄回闭环 |
| 操作按钮 | 状态非 已追回/超时终止：**「登记坏件到货」** → 状态"已追回"，停止提醒 |
| 自动机制 | 后台每日扫描：发货满 7 天进提醒 → 每 7 天提醒一次(系统内/企微) → **超 60 天自动"超时终止"** |

---

### 5. 改进记录 Improvement Record

| 项 | 说明 |
|----|------|
| 定位 | 记录已发生的改进（部件编码+措施）；登记提交时**自动比对"改进-再发"** 并评论提醒 |
| 维护 | 质量/管理员新增（可在配件行"改进追踪项"下拉选到对应项） |

---

### 6. 索赔清单 Claim List

| 项 | 说明 |
|----|------|
| 定位 | 按 月份 + 供应商 汇总的索赔对账清单（M3） |
| 自动 | cron 每月 1 日 2:00 自动生成上月清单 |
| 操作按钮 | 新建空白单时：**「生成上月清单」**（手动补跑）；采购可编辑确认、导出 |
| 打印 | **供应商索赔清单** 版式，直接给供应商对账 |

## 三、主数据 / 字典维护页

| 页面 | 能做什么 | 备注 |
|------|---------|------|
| **配件主档** Spare Part | 维护 K3编码/E10品号/名称/供应商/索赔需求/ERP物料 | 登记自动带出源；**支持 Excel 批量导入**（见交接手册 §8） |
| **整车发货** Vehicle Delivery | 车辆档案：铭牌/车型/出厂日期/**购车客户/对接人** | 输铭牌带出客户的关键数据源；支持导入 |
| **配件登记** Special Part Registration | 特殊配件跟踪：订单号/状态(生产中/已装机…) | 铭牌命中自动显示 |
| **售后选项** After Sales Option | 可视化维护所有下拉：服务类型/索赔需求/坏件寄回/改进追踪项…（改完即同步到表单） | **不需要改代码**，业务人员可自维护 |
| **故障字典** | 故障大类 → 部件 → 现象 三级增删改 | 登记三级点选的数据源 |
| **售后资料库** File | 浏览自动归档的故障照片/文件（按客户/年月/部件目录） | 归档由系统自动完成 |
| **售后设置** After Sales Settings | 出库仓库 / 企微 webhook / 通知开关 / 外部系统接口 | 单例设置，管理员 |

## 五、非页面能力（命令/后台，不含界面）

| 能力 | 触发方式 | 说明 |
|------|---------|------|
| 配件价格表导入 | bench 命令 | Excel → 配件主档（幂等，**导入前自动预检出校验报告**） |
| 整车/客户收货导入 | bench 命令 | Excel → 车辆+客户档案（同上，预检不通过不写任何数据） |
| 上线就绪体检 | bench 命令 | ✅/⚠️/🔴 分级报告 |
| 售后登记 Excel 导出 | 列表页「导出 Excel」按钮 | 按当前用户可见范围导出 xlsx |
| 回访/审批超时扫描 | 后台 daily_long | 待回访超3天 / 待审批超2天 → 站内+企微提醒（当天同单去重） |
| 敏感字段变更日志 | 自动（on_update） | 索赔动作/OA状态/回访状态等改动在单据评论留痕（谁改+前后值） |
| 数据权限细化 | 自动（顶层钩子） | After Sales 普通角色只看自己登记的单；主管/采购/质量按原角色 |
| 移动端适配 | 自动（app_include_css） | 小屏收紧间距、子表横滚、看板纵向堆叠 |
| 旧件追回每日扫描 | 后台 daily_long | 提醒/超时 |
| 批量隐患每日扫描 | 后台 daily_long | 近7天同部件≥3起 → 预警 |
| 索赔清单月度生成 | 后台 cron | 每月1日2点 |
| 企微/外部推送 | 设置后自动 | webhook 填了即推 |

> 以上命令见《交接与运维手册》§7/§8。

## 六、一句话导航（演示/验收常用）

```
录单：售后登记 → 提交审批
审批：主管账号打开登记 → 审批通过
出库：自动生成的索赔单 → 生成出库单
追回：旧件追回 → 登记坏件到货
对账：索赔清单 → (生成上月清单/打印)
治本：登记单/预警 → 质量闭环 → 标记完整闭环
改字典：售后选项 / 故障字典（无需改代码）
查附件：售后资料库
配置：售后设置
```
